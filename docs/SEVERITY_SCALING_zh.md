# 严重度适配：第 0 步免训练缩放探针（预注册）

状态：**两个探针均已跑完并回填（2026-11-24）**。协议分别预注册于
commit 0430b80/04a4bf3/908d727（探针1）与 2e3026d（探针2），均先于结果。
结论：免训练缩放与"按 s 打折"两条免训练路线**均判"不支持"**（§4、§5b；
protan 轻度端确有统计明确的内部最优 w=0.75，但差半格未过判据，如实记录）；
反向发现"轻度档欠矫正"（端点修正闭合率仅 ~44–46%）；训练式条件化若立项，
目标重定向为**提高闭合率/改善修正方向**而非减弱幅度（§5b-3）。待用户决策。

## 1. 要检验的假设

自有方法的模型族与训练数据全部生成于二色端点严重度（Machado s=1.0）。
若"观察者所需修正随严重度近似线性缩放"成立，则**无需任何再训练**：
对已有的线性化 α=0.5 端点模型做后处理

> out_w = x + w·(model(x) − x)，w∈[0,1] 按目标严重度 s 离线标定

即可覆盖异常三色视（0<s<1）人群。机理依据：Machado 2009 仿真本身对 s
是线性插值（`cvd_simulation.py`：`sim_s = (1−s)·原图 + s·端点`），
一阶近似下逆算子（修正）也应随 s 线性缩。该近似的已知盲区：缩放只改修正
**幅度**、不改其作用的**色区**——这正是本探针要量出来的东西。

## 2. 实验设置（全部预注册，运行前写定于 severity_probe.py 头注释）

- 数据：v3 自然图 validation 1,753 张（`cvd_fixed_v3.csv`），
  评估顺序与种子同 evaluate.py；**test 封存不动**；
- 模型：`ablation_linearized_20261123/<axis>/author_<axis>_alpha0.5/final.pt`
  （即自有方法 α=0.5 成员），protan/deutan 各一遍；
- 网格：w∈{0,0.05,…,1.00}（21 档）× s∈{0.25,0.50,0.75,1.00}；
- 指标：三件套与现行惯例逐字一致（TCC 配对增益、SSIM、色度保真）；
  保真与 SSIM 与 s 无关（输出 vs 原图），TCC 增益按各 s 仿真域计算；
- 选择规则：**w\*(s) = 约束带（平均色度保真 ≥0.9400）内平均 TCC 增益最大的
  w；并列取更小 w**；若带内无点则取无约束 argmax 并标注"越带"；
- 自检（任一失败即整体作废）：
  1) 批式 TCC 与 metrics.tcc 数值一致（<1e-6）；
  2) w=0 时每档增益恒等于 0（逐位）；
  3) w=1∧s=1.0 与该 run 既有 eval 的逐图指标最大偏差 <5e-4。

## 3. 判读规则（预注册，不许事后放松）

- **标定有用**（helps）：某 s 档，配对 Δgain = gain(w\*)−gain(1) 的
  95% 置信区间下界 >0 **且** 均值 ≥0.3 TCC（本项目视为可决策的最小差距，
  参照 α 族表内 0.09–0.4 的级差）；
- **缩放假设成立**（consistent）：w\*(s) 随 s 单调不减，且对
  s∈{0.25,0.50,0.75} 满足 |w\*(s)−s| ≤0.10；
- **两个都成立** → 免训练缩放可作为严重度适配主方案，训练式条件化
  （混档在线仿真）降为可选增强；
- **只成立一个或都不成立** → 如实记录，混档训练第 1 步照常立项；
- **本探针不能说明的事（自设上限，防自我安慰）**：没有"固定 s 专训模型"
  对照，它只能证明"标定带来多少提升"，**不能**证明"标定已达到训练式
  条件化的天花板"。该对照（s=0.5 专训微调，约 75 分钟/轴）列为后续
  决策点，不在本步内偷跑。

## 4. 结果（2026-11-24 回填，两轴 COMPLETE，自检全过）

一致性核对：batched-TCC vs metrics.tcc 偏差 2.4e-7；w=0 增益恒 0；
w=1∧s=1.0 与该 run 既有 eval 逐图最大偏差 deutan 5.7e-5 / protan 1.3e-4
（阈值 5e-4，链路可信；端点数字复现 6.035/5.024、保真 0.9798/0.9805，
与 METHOD_zh α 族表一致）。

预注册判读表（两轴一致）：对每个 s∈{0.25,0.5,0.75,1.0}，约束带内增益最大
的 w* **恒等于 1.00**，Δ(w*−1)=0，"标定有增益"=否；"w*≈s"=否（仅 s=1 档平凡成立）。

**判读结论（按预注册规则）**：两轴所有 s 档 w*≡1.00、Δ=0，"标定有增益"=否、
"w*≈s"=否 → 免训练缩放路线关闭，第 1 步照常推进。数据：
`severity_probe_20261124/<axis>/{grid_summary,per_image_grid}.csv`。

**对这一负结果的严谨性自评（必须先于任何引申）**：事后核查发现
TCC 平均增益与保真对 w 在全部 (轴,s) 组上**严格单调**（增/减，4/4 True）。
blend ray 是（原图, 端点输出）的凸组合，两端点的 (增益,保真) 各占一极、
沿射线单调过渡，**数学上就不存在内部最优点**——预注册判据输出"否"
的先验概率接近 1。故本轮结论的正确表述是：

1. **成立**：全局标量缩放是**结构性错误的旋钮**——它不能产出任何
   (端点模型, 原图) 权衡线之外的新工作点，因而**不可能**替代训练式
   严重度条件化。第 0 步到此为止有效。
2. **不成立（禁止引申）**：不能由此说"轻度用户不需要/不受过矫正影响"。
   受害图分析显示：w=1 下 deutan s=0.25 有 2.2%（38 图）、protan 0.8%
   （14 图）负增益（负值均值约 −1.1）；对这批图 w 砍半（0.5）后平均
   增益仍 −0.57，**唯有 w→0（关掉修正）才转正**——统一旋钮救不了它们，
   需要的是逐图/训练层面的方向修复。且 TCC 增益"越大越好"的定义对
   过矫正天然钝感（对比度只要被推大就记分），本轮指标体系看不出
   "修正过头"的伤害 ≠ 伤害不存在（文献主观证据在案：Zhu22 五被试
   100% 档反而变差）。此为本探针的**设计教训**：检验"是否矫枉过正"
   需要目标对齐型指标（如仿真域排序一致性/与正常视觉的匹配度），
   或主观实验——列入第 1 步评估协议扩展。
3. **留给第 1 步的实质战利品**：(a) blend ray = 现成基线曲线
   （每轴每 s 一条 (增益,保真) 单调线），训练式条件化模型的成功判据
   从此有了数学内容——**必须在同保真水平上压过该线**（射线之外无免费
   点，压线才算真改进）；(b) 受害图修复率（2.2%/0.8% 基线在案）；
   (c) 评估轴需补目标对齐指标（见 2），否则条件化模型的价值同样
   无法被现有三件套证明。

流程教训入档：预注册判据在设计时应先做"该统计量在零假设下是否可能
取非平凡值"的先验核查——本轮"helps"判据对退化情形不设防。

## 5b. 探针 2 结果：目标对齐轴（2026-11-24 回填，协议预注册于 2e3026d）

新尺子：MATCH = −平均|仿真_s(输出) 像素对分离度 − 正常视图原图分离度|
（罚超调）；CLOSURE = 缺陷对闭合率（封顶 1）；OVERSHOOT = 可见对超调量。
τ=6（Lab L1，CCPR 惯例适配已声明；{3,10} 敏感性存 tau_sensitivity.csv）。

| s | w_match(deutan) | w_match(protan) | Δ CI(protan s=.25) | 闭合率@w1 (D/P) | 超调@w1 (D/P) |
|---|---|---|---|---|---|
| 0.25 | 0.95（CI 跨零） | **0.75（CI [+0.106,+0.144] 明确为正）** | 内部最优存在 | 0.460 / 0.438 | 1.89 / 2.04 |
| 0.50 | 1.00 单调 | 1.00 单调 | — | 0.335 / 0.315 | 2.05 / 1.91 |
| 0.75 | 1.00 单调 | 1.00 单调 | — | 0.300 / 0.266 | 2.37 / 1.94 |
| 1.00 | 1.00 单调 | 1.00 单调 | — | 0.331 / 0.264 | 2.62 / 2.03 |

预注册三判据：单调不减 D✓P✓；w_match(0.25)≤0.70 **D✗P✗**（protan 差半格）；
Δ CI>0 D✗P✓。**两轴均判"不支持"，如实记录。**

实质发现（比"支持/不支持"更有价值，方向与"按需打折"假设相反）：

1. **轻度档欠矫正而非过矫正**：s=0.25 处，完整端点修正对缺陷对的闭合率
   只有 ~44–46%——轻度用户的视图仍远未接近正常视图，MATCH 因此几乎全程
   奖励继续加大 w。"端点修正对轻度用户太强"的前提在测量上不成立：
   修正在绝对量级上对谁都偏弱（各 s 闭合率全 <50%，连 s=1.0 也只有 26–33%）。
2. **超调确实存在且可测**（可见对平均超调 ~1.9–2.6 Lab L1，CI 明确离零），
   protan s=0.25 出现真实内部最优 w=0.75（Δ 的 CI 全正）——即"打折"在
   protan 轻度端不是零、但幅度远小于"按 s 等比打折"的原始主张；deutan
   峰值在 0.95、与 w=1 统计上不可分。
3. **对第 1 步的重新定向**：条件化训练若立项，其可检验目标应从
   "为轻度用户减弱修正"改为"**在同幅度下提高闭合率/改善修正方向**"——
   即学出比端点模型更对准该档缺陷的 d(s) 向量，而不是复刻一个更小的 w。
   MATCH/OVERSHOOT/CLOSURE 三量已可零成本沿用（severity_probe2.py）。

边界声明不变：设计型指标未经人类判断校验；s 为建模约定；单 seed；
成文时全部如实标注。
